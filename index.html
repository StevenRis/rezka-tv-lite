Каталог ещё не загружен.

Список подготовлен на сервере GitHub и не обновляется автоматически. Кнопка перечитывает опубликованный снимок.

Подключить ноутбук

Запусти новый backend на ноутбуке и введи шестизначный код с его экрана. Код в чат отправлять не нужно.

Ноутбук ещё не подключён.

Адрес приложения не меняется. Ноутбук и терминал должны оставаться включёнными. После нового запуска backend понадобится новый адрес и код. Внутри поля ввода цифровые кнопки вводят цифры.
