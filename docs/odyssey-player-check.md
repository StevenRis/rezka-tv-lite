## Серверный результат

GitHub Actions получает HTML страницы, HTTP 200. В ней присутствует initCDNMoviesEvents. Параметры url и quality имеют значение false. В блоке b-player__restricted__block_message указано: «К сожалению, это видео не доступно в вашем регионе».

Диагностический скрипт обнаружил ограничение и не отправлял запрос на получение потока. Потоки не извлекались, не скачивались и не публиковались. Код не решает проверки защиты и не использует cookies, авторизацию, прокси или подмену региона.

## Вывод

Доступность HTML и каталога с сервера GitHub не означает доступность видео. Воспроизведение «Одиссеи» через сервер GitHub в этой конфигурации не подтверждено и блокируется региональной доступностью.

Следующий проверяемый вариант: backend в регионе, в котором просмотр разрешён пользователю, например европейское размещение для пользователя в Польше. До реализации нужно подтвердить получение потока из выбранного места, условия доступа, срок действия адреса, необходимость cookies/Referer, привязку к IP и совместимость MP4/HLS с телевизором.

Снимок catalog.json остаётся только списком метаданных. Статические ссылки из него открывают оригинальный сайт. Обещать просмотр внутри приложения на основании успешного тестового MP4 нельзя.
