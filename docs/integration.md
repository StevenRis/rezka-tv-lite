## 0.1.2

scripts/catalog_probe.py извлекает максимум 24 уникальные карточки публичной главной страницы. Только название, краткие сведения и ссылка. Выход проверен по настоящему ответу.

Подготовленный catalog.json публикуется рядом с HTML. Приложение читает снимок со своего домена, постоянный сервер для него не нужен. Нет авторизации, cookies, случайных прокси, извлечения потоков или обхода проверок.

Карточка открывает оригинальную страницу в браузере. Собственное воспроизведение Rezka не реализовано. Снимок не обновляется автоматически: кнопка перечитывает опубликованный JSON. Workflow только читает репозиторий и выводит JSON; публикация — отдельный обычный коммит.

Каталог отображён в тестовом Chromium: 24 карточки. Проверка на Philips ещё нужна. Следующий отдельный этап — исследование разрешённой интеграции проигрывателя, форматов и доступности потоков.
